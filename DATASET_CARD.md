# IDEN-VLN dataset

The compact release is in [dataset/](dataset/). See the [full data card](dataset/DATA_CARD.md), [checksums](dataset/release_checksums.json), and [reproducibility boundaries](docs/REPRODUCIBILITY.md).

There are 2,500 high-level tasks and 3,291 step-task segments. Raw simulator assets and model weights are not included. Dataset licensing is deferred pending source-derived-rights review; no CC BY grant is applied. See [dataset reuse notice](dataset/LICENSE.md) and [current license metadata](dataset/license_metadata.json). The scoped MIT code grant does not cover the dataset.
