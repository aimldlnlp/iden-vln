# IDEN-VLN dataset

The compact release is in [dataset/](dataset/). See the [full data card](dataset/DATA_CARD.md), [checksums](dataset/release_checksums.json), and [reproducibility boundaries](docs/REPRODUCIBILITY.md).

There are 2,500 high-level tasks and 3,291 step-task segments. Raw simulator assets and model weights are not included. Limited owner-controlled permission for non-commercial academic research is documented in [project terms](dataset/TERMS_OF_USE.md), with a [private acceptance procedure](docs/DATA_ACCESS.md). Source-provider rights remain separate; no CC BY grant is applied. See [dataset reuse notice](dataset/LICENSE.md) and [current license metadata](dataset/license_metadata.json). The scoped MIT code grant does not cover the dataset.
