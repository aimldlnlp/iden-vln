# IDEN-VLN dataset

The compact release is in [dataset/](dataset/). See the [full data card](dataset/DATA_CARD.md), [checksums](dataset/release_checksums.json), and [reproducibility boundaries](docs/REPRODUCIBILITY.md).

There are 2,500 high-level tasks and 3,291 step-task segments. Raw simulator assets and model weights are not included. Licensing remains unresolved; no blanket license is introduced by this update.
